# Code of Conduct

## Purpose

This project is primarily an individual research project. Contributions, feedback, and discussion are welcome, but there is currently no formal community or moderation structure.

This document simply sets expectations for anyone interacting with the project.

## Expected Conduct

Contributors and users are expected to:

- Communicate respectfully and professionally.
- Provide constructive feedback and discussion.
- Respect differing technical opinions and approaches.
- Avoid personal attacks, harassment, discrimination, or other inappropriate behaviour.
- Respect the privacy and personal information of others.

## Project Discussions

Issues, pull requests, and other project discussions should remain focused on the project and its technical work. Constructive criticism of the code, methodology, documentation, or results is encouraged.

Contributions may be declined or removed if they are clearly inappropriate, unrelated to the project, or inconsistent with these expectations.

## Reporting Concerns

If you encounter behaviour that violates these guidelines, please raise the matter directly with the project maintainer through the contact details provided in the repository.

As this is currently a small, individually maintained project, concerns will be handled on a case-by-case basis.

## Scope

This Code of Conduct applies to interactions within this project's GitHub repository and to other spaces directly associated with the project.
